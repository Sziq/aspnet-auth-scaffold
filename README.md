# aspnet-auth-scaffold

ASP.NET MVC 5 authentication scaffold with Identity, external login providers, and two-factor auth.

## Features

- User registration and login
- Password reset flow
- External login integration
- Two-factor authentication
- Account management

## Getting Started

1. Open `aspnet-auth-scaffold.sln` in Visual Studio
2. Restore NuGet packages
3. Press F5 to run
